# CT-06 – Receita com sucesso

## Objetivo

Validar a criação de uma receita com sucesso.

## Pré-condições

- Usuário com login feito.

## Passos

1. Acessar tela de nutrição
2. Clicar no botão de adicionar receita
3. Preencher todos os dados relacionados à receita
4. Clicar para confirmar a realização de checkin

## Resultado Esperado

Receita criada e exibida na tela de nutrição.
