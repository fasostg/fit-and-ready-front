# CT-04 – Checkin com sucesso

## Objetivo

Validar a realização de um checkin com sucesso.

## Pré-condições

- Usuário com login feito.
- Usuário com algum treino criado.

## Passos

1. Acessar tela de início
2. Clicar no botão de realizar checkin
3. Selecionar algum treino criado
4. Preencher todos os dados relacionados ao checkin
5. Clicar para confirmar a realização de checkin

## Resultado Esperado

Checkin feito e exibido na tela de início.
