# CT-02 – Treino com sucesso

## Objetivo

Validar a criação com sucesso de um treino.

## Pré-condições

- Usuário com login feito.

## Passos

1. Acessar tela de treino
2. Clicar no botão de adicionar treino
3. Preencher todos os dados do treino
4. Inserir pelo menos um exercício com os dados também preenchidos
5. Clicar para confirmar a criação do treino

## Resultado Esperado

Treino criado e exibido na tela de treino.
