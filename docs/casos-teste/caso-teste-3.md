# CT-03 – Treino com falha

## Objetivo

Verificar a criação com falha de um treino.

## Pré-condições

- Usuário com login feito.

## Passos

1. Acessar tela de treino
2. Clicar no botão de adicionar treino
3. Preencher todos os dados do treino
4. Não inserir nenhum exercício
5. Clicar para confirmar a criação do treino

## Resultado Esperado

Treino não deve ser criado e deve ser exibida mensagem de erro pedindo para inserir algum exercício.
