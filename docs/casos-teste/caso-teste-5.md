# CT-05 – Checkin com falha

## Objetivo

Verificar a realização de um checkin falha.

## Pré-condições

- Usuário com login feito.

## Passos

1. Acessar tela de início
2. Clicar no botão de realizar checkin
3. Preencher todos os dados relacionados ao checkin sem selecionar treino
4. Clicar para confirmar a realização de checkin

## Resultado Esperado

Checkin não criado e exibida mensagem de erro para selecionar treino.
